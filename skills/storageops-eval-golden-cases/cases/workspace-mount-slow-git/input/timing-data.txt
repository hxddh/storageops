# Timing Comparison

| Operation | Local SSD | BOS Mount |
|---|---|---|
| OpenClaw startup | ~1 min | ~3 min |
| Single conversation feedback | ~12s | ~55s |
| `git status` | <1s | ~30s |
| `ls -la workspace/` | <0.1s | ~3s |
| File save in editor | instant | 2-5s |
