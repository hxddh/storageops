# Severity Rubric

| Severity | Criteria |
|---|---|
| critical | Data loss, credential exposure, security breach, or full production outage. |
| high | Major production degradation, replication failure, or widespread failed writes/reads. |
| medium | Isolated workload failure, recoverable data access issue, or clear workaround. |
| low | Informational planning, tuning request, or non-production issue. |

Always raise severity when user reports missing objects, leaked credentials, public exposure, or irreversible operations.
