# Pricing Assumptions

last_verified: 2026-06-02

Use this reference only as a dated checklist for cost discussions. Before quoting
numbers, confirm the provider, region, storage class names, pricing date, and
whether the user wants rough estimates or invoice reconciliation.

## Must Confirm

- provider and region
- pricing date and currency
- storage class names and minimum-duration rules
- minimum billable object size per class
- retrieval, restore, and request pricing
- whether transfer, tax, support, and discounts are in scope

## Method

1. Start with the user's inventory or billing export.
2. Map each object to its provider-specific storage class.
3. Apply confirmed minimum billable size and minimum-duration rules.
4. Add request, retrieval, restore, and transfer charges only when evidence is
   available.
5. State every assumption beside the estimate.

Do not treat historical examples in SKILL.md, invoices, or another provider's
pricing page as current pricing.
