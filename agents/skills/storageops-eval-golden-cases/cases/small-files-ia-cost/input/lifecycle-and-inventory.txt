# Lifecycle Configuration (XML)

```xml
<LifecycleConfiguration>
  <Rule>
    <ID>MoveToIA-After30Days</ID>
    <Filter>
      <Prefix>logs/</Prefix>
    </Filter>
    <Status>Enabled</Status>
    <Transition>
      <Days>30</Days>
      <StorageClass>STANDARD_IA</StorageClass>
    </Transition>
  </Rule>
</LifecycleConfiguration>
```
